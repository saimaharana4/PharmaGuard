# Archived demonstration

The final public narrated PharmaGuard demo is stored here so it remains available
without a running Google Cloud environment.

- Video: [pharmaguard-demo.mp4](pharmaguard-demo.mp4)
- YouTube: https://youtu.be/J2ItTcts2ek
- Duration: 3 minutes 4 seconds (184 seconds)
- Resolution: 1920 x 1080
- Video/audio: H.264 / AAC in an MP4 container
- File size: 16,160,498 bytes
- SHA-256: `7729054a884c9108d09203acabc24ed5e8ade80e27346195f127a47adebc1975`

The archived file is byte-for-byte identical to the finished voiceover master used
for the public demo. It contains the application walkthrough, the GitLab Duo retrieval
repair and validation, and the Google Cloud service view. The cover image is project
branding; the recorded application and workflow footage are in the video.

The source snapshot is described in [source provenance](../source-provenance.md).
This recording is historical demonstration evidence, not a live availability check.
Deployment configuration, dataset access and credentials are still required to run
the application. This research prototype does not provide medical advice or prove
drug-event causality.

Only this final edited recording is intentionally versioned. Raw takes and other local
recordings remain excluded, and `docs/media/` is excluded from Docker and Cloud Build
upload contexts.
