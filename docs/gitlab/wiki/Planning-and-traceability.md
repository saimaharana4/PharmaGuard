Requirements cover deterministic metrics, temporal cutoffs, canonical citations, recall and
critical evidence, staging isolation, newest-five session memory and human release approval.
Test Cases were copied from the **checksum-verified v2 snapshot**, not generated from model
answers. Each retains reviewed provenance, evidence IDs and a link to its executed result.
Live LLM judging supplements these labels and never rewrites them.

Workflow: Ready → In progress → Review, with Blocked for a real unmet dependency. Closed
items appear in the board's native closed list. Child Tasks #28–#30 track report and dashboard
validation. No artificial deadlines, estimates or completion history have been invented.

The future Duo demonstration is tracked in #10. It has not been started by this documentation
work. A successful baseline must remain available while a separately authorized regression
branch demonstrates diagnosis and one bounded repair.
